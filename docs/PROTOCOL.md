# AULA F87 PRO 有线配置协议

这份文档记录本项目用到的 F87 PRO 有线配置协议：命令、数据格式和每个字节的含义。它是为了让键盘在官方驱动停更后还能继续配置（互操作），内容都经过实机读写验证。

置信度：✅ 实机确认 · 🟡 推断，未实机验证 · ❓ 未知

> 非官方文档，和 AULA 没有关系。往键盘写数据有风险，请先读后写、写前备份。

---

## 1. 设备

| 项目 | 值 |
|---|---|
| 有线 VID:PID | `258A:010C`（浏览器选择框里显示为 “Gaming Keyboard”） |
| 配置接口 | UsagePage `0xFF00`、Usage `0x01`，Feature Report ID `0x06` |
| 2.4G 接收器 VID:PID | `3554:FA09`（配置接口 UsagePage `0xFF02`、Usage `0x02`，本项目暂不支持） |
| 型号指纹 | 命令 `0x82` 读回 6 字节，F87 PRO = `03 00 00 00 01 0B` ✅ |

- 同一个 VID:PID 可能对应同系列的其他型号，要靠指纹区分。指纹不对时本驱动只读不写。
- 键盘要在 **Windows 模式（Fn+W）** 才会响应配置命令。

## 2. 帧格式（Feature Report 0x06）✅

发出去的每一帧是 519 字节（WebHID 的 `sendFeatureReport` 不含报告 ID）：

```
偏移  长度  含义
0     1    cmd    命令号（读命令 = 写命令 | 0x80）
1     1    sub    子参数（层号等）
2     1    0x00
3     1    总包数 = ceil(数据长度 / 512)
4     1    包序号（从 0 开始）
5     2    本包数据长度（小端，≤ 512）
7     512  数据（读请求时为空）
```

- **读**：发请求帧 → 等约 20ms → `receiveFeatureReport(0x06)`。回复的头部会回显命令号：`06 cmd sub 00 包数 序号 长度低 长度高`，数据跟在后面。
- **回复长度不固定** ✅：按键矩阵回复 520 字节，灯效块只有 136 字节。判断方法：第 0 字节是 `0x06` 且第 1 字节等于命令号时，去掉第 0 字节，数据从第 7 字节开始。
- **写**：每包之间隔约 20ms；发送失败可以重试（本驱动最多 3 次，间隔 70ms）。写完再读一次核对。

## 3. 命令

本驱动只用下面这些命令：

| 写 | 读 | 内容 | sub | 长度 |
|---|---|---|---|---|
| — | `0x82` | 型号指纹 | 1 | 6 |
| `0x04` | `0x84` | 灯效 / 全局设置块 | 0 | 128 |
| `0x0A` | `0x8A` | 颜色表（调色板） | 0 | 512 |
| `0x03` | `0x83` | 按键矩阵 | 层号 0–3 | 512 |

协议里还有宏（`0x05/0x85`）、游戏模式（`0x06/0x86`）、实时灯光帧（`0x08`、`0x0E`）、恢复出厂（`0x11`）等命令，本驱动都不发送。

## 4. 灯效 / 全局设置块（128 字节）✅

| 偏移 | 含义 |
|---|---|
| `0x03` | 防抖，0–4（官方界面显示为 1–5 档），出厂 1 |
| `0x0A` | 当前灯效的序号（1–18，见下表） |
| `0x18` | 休眠时间，单位 30 秒（见下表），出厂 10 = 5 分钟 |
| `0x3A + 2×(n−1)` | 灯效 n 的亮度，0–4（4 最亮，0 可能是灭灯） |
| `0x3B + 2×(n−1)` | 灯效 n 的 `(速度 << 4) \| 颜色`，速度 0–4，颜色 0–7 |
| `0x7E`、`0x7F` | 签名 `5A A5` |

其他字节的含义没有完全确认，本驱动写入时原样保留，只改上表里的字节。

**灯效序号**（✗ = 固件不支持，切过去键盘会灭灯 ✅）：

|---|---|---|---|
| 1 | 常亮 Always On | 10 | 川流不息 Retro Snake |
| 2 | 呼吸 Breathing | 11 | 随波逐流 Neon Stream（出厂） |
| 3 | 梦幻彩虹 Rainbow（颜色固定） | 12 | 如影随形 Reactive |
| 4 | 一触即发 Flash Away | 13 | 正弦光波 Sine Wave |
| 5 | 雨中漫步 Raindrops | 14 | ✗ 左右扫描 Side Scan |
| 6 | ✗ 彩虹轮盘 Rainbow Wheel | 15 | 旋转风车 Windmill（颜色固定） |
| 7 | 涟漪扩散 Ripples | 16 | 七彩瀑布 Color Waterfall（颜色固定） |
| 8 | 繁星点点 Twinkling Stars | 17 | 花开富贵 Blossoming（颜色固定） |
| 9 | ✗ 踏雪无痕 Vanishing Trail | 18 | ✗ 旋转风暴 Rotating Storm |

**颜色编号**：0–6 = 调色板里的 7 种颜色（出厂：红、绿、蓝、黄、品红、青、白），7 = 多彩。

## 5. 颜色表（512 字节）✅

- 每 21 字节一段 = 7 种颜色 × `[R, G, B]`。第 n 段（从偏移 `21×n` 开始）是灯效 n 用的 7 种颜色。
- 第 0 段为空。出厂时第 1–13 段都是同一套颜色：红 `FF0000`、绿 `00FF00`、蓝 `0000FF`、黄 `FFFF00`、品红 `FF00FF`、青 `00FFFF`、白 `FFFFFF`。
- 签名 `5A A5` 在偏移 `0x1FA`。
- 本驱动把同一套 7 色写进第 1–13 段，让所有灯效共用一个调色板；其他字节原样保留。在键盘上按 Fn+Delete 循环的就是这几种颜色。

## 6. 按键矩阵（每层 512 字节）✅

- 每层 128 个槽位 × 4 字节。层号：0 = 默认层、1 = FN1 层（按住 Fn 时）、2 = FN2 层、3 = Tap 层（❓ 未研究）。
- 第 127 个槽位是签名 `00 00 5A A5`。
- 每个按键对应一个固定槽位，例如 Esc = 0、`` ` `` = 1、Tab = 2、CapsLock = 3、LShift = 4、LCtrl = 5、F1 = 12、Space = 35、Fn = 59。完整对照表见 [`driver/keycodes.js`](../driver/keycodes.js) 的 `KEYS`。
- **FN1 层里值为 `00 00 00 00` 的键 = 沿用默认层的功能** ✅（出厂 FN1 层的 A 是空的，按 Fn+A 打出 a）。

### 4 字节键值 `[b0 b1 b2 b3]`

| b0 | 类型 | 格式 |
|---|---|---|
| `00` | 键盘键 / 组合键 | `[00, 修饰键位图, 第二个键, 键]`，键是 HID 键盘用法码 |
| `01` | 鼠标 | `[01, 按键号, 连击次数, 间隔]` |
| `02` | 多媒体 | `[02, 00, 用法码高字节, 用法码低字节]`（HID Consumer 用法码） |
| `03` | 宏 | `[03, 循环模式, 次数, 宏序号]`（本驱动不支持） |
| `07` | 键盘内置功能 | `[07, 00, 00, 功能号]` |
| `08` | 灯光控制 | `[08, 项目, 方向, 区域]` |
| `0D` | Fn 键 | `0D 00 00 00` = FN1，`0D 01 00 00` = FN2 |
| `00 00 00 00` | 无功能 | 在 FN1 层里表示“沿用默认层” |

**键盘键**：修饰键位图 1 LCtrl · 2 LShift · 4 LAlt · 8 LWin · 0x10 RCtrl · 0x20 RShift · 0x40 RAlt · 0x80 RWin。例：空格 `00 00 00 2C`，Ctrl+C `00 01 00 06`。单独一个修饰键写成 `00 位图 00 00`（例如 LShift = `00 02 00 00`，出厂就是这样写的）。

**鼠标**：按键号 1 左 · 2 右 · 3 中 · 4 后退 · 5 前进 · 8 滚轮上 · 9 滚轮下。普通单击的连击次数写 1，例如左键 `01 01 01 00`。

**多媒体**（部分）：播放/暂停 `0x0CD`、静音 `0x0E2`、停止 `0x0B7`、上一曲 `0x0B6`、下一曲 `0x0B5`、音量 + `0x0E9`、音量 − `0x0EA`、计算器 `0x192`、邮件 `0x18A`、我的电脑 `0x194`、浏览器主页 `0x223`、收藏夹 `0x22A`、屏幕亮度 +/− `0x06F` / `0x070`。

**键盘内置功能 `07`**：

| 功能号 | 功能 | 出厂位置 |
|---|---|---|
| `01` | 锁 Win 键 | |
| `02` | 锁键盘 | |
| `04` | 复位键盘 | Fn+Esc |
| `05` / `06` / `07` | 蓝牙设备 1 / 2 / 3（长按 3 秒配对） | Fn+1 / 2 / 3 |
| `08` | 2.4G 模式（长按 3 秒配对） | Fn+` |
| `0A` | ❓ 说明书没写 | Fn+G |
| `0C` | 灯带显示电量 | Fn+B |
| `18` / `19` / `1A` / `1B` | Windows / Android / Mac / iOS 模式 | Fn+W / Q / E / R |

**灯光控制 `08`**：项目 0 灯效 · 2 颜色 · 3 亮度 · 4 速度；方向 0 循环切换 · 1 加 · 2 减；区域 0 键盘背光 · 1 侧灯 · 2 灯带。例：亮度 + `08 03 01 00`（出厂在 Fn+↑），切换颜色 `08 02 00 00`（Fn+Delete）。

**常用命令**其实就是普通组合键，例如“关闭窗口”= Alt+F4 = `00 04 3D 00`，“显示桌面”= Win+D = `00 08 07 00`。

## 7. 恢复出厂

本驱动不发恢复出厂命令 `0x11`。做法是把出厂值重新写一遍：灯效块（只写第 4 节表里的字节）→ 颜色表 → 默认层 → FN1 层。出厂值来自第一次实机读取，见 [`driver/factory.js`](../driver/factory.js)。

## 8. 本驱动的安全做法

- 先读后写：每次写入前重新读取键盘，只改目标字节，其他字节原样保留。
- 写入前检查长度、签名和改动范围，不在允许范围内的改动直接拒绝。
- 写入前自动备份，写完读回核对。
- 不做固件升级，不发送上面列表以外的命令。
